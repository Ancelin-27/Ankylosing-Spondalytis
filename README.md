Dataset Description :
This dataset contains clinical and demographic information related to Ankylosing Spondylitis, a chronic inflammatory arthritis that primarily affects the spine. The dataset consists of 500 patient records, with each record representing an individual patient. It includes features such as age, gender, duration of chronic back pain, presence of morning stiffness, spinal flexibility, HLA-B27 genetic marker status, inflammation level, and fatigue level. These attributes reflect common symptoms and risk factors associated with Ankylosing Spondylitis. The target variable indicates whether a patient has Ankylosing Spondylitis or not. The dataset is clean and well-structured, making it suitable for exploratory data analysis and supervised machine learning classification tasks. It can be used to build and evaluate models such as Decision Trees, Random Forests, Logistic Regression, and K-Nearest Neighbors. This dataset is ideal for academic projects, healthcare analytics, and learning applications in medical data science.
